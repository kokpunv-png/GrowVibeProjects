# Прототип MVP: мониторинг новых точек (Акмолинская область)

Реализует шаги P0 из [prd.md](../prd.md) на минимальном уровне: сбор → модерация → доставка.

## Пайплайн

```bash
powershell -File .\collect_report.ps1          # 1. Сбор данных (СМИ + Google News) -> pending_review_YYYY-MM.csv
# ... вручную открыть CSV, заполнить колонку "Статус": да / нет ...
powershell -File .\approve_report.ps1          # 2. Модерация -> report_YYYY-MM_final.csv
powershell -File .\send_report.ps1 -Execute    # 3. Доставка на email/Telegram
```

## Файлы

| Файл | Назначение |
|---|---|
| `collect_report.ps1` | Собирает новости (региональные СМИ + Google News RSS), извлекает поля эвристикой, дедуплицирует, выгружает в `../output/pending_review_YYYY-MM.csv` |
| `approve_report.ps1` | Фильтрует по колонке "Статус", выгружает подтверждённые записи в `../output/report_YYYY-MM_final.csv` |
| `send_report.ps1` | Отправляет финальный CSV на email и/или в Telegram. По умолчанию — dry run, реальная отправка только с `-Execute` |
| `config.example.json` | Шаблон настроек email/Telegram. Скопировать в `config.json` и заполнить своими данными (файл в `.gitignore`, никому не передавать) |

## Источники данных сейчас

- Региональные СМИ (через встроенный RSS-поиск): kokshetoday.kz, akmolinform.kz, apgazeta.kz
- Google News RSS — как дополнительный широкий охват. **Ограничение:** по условиям Google этот фид предназначен для личного некоммерческого использования в feed-ридере — для продакшн-рассылки внешним получателям нужно либо убрать, либо согласовать использование отдельно.

## Не реализовано (следующие итерации, см. Roadmap в prd.md)

- Официальный сайт акимата (akmo.gov.kz) — при обращении рвётся TLS-цепочка сертификата, нужно разбираться отдельно (не стали "тихо" отключать проверку сертификата для гос.сайта).
- Госреестры / ОКЭД, 2ГИС API, соцсети — вне MVP по самому PRD.
- Извлечение точного адреса (улица/дом) — колонка есть, но не заполняется.
- Автозапуск 1-го числа месяца (P0 в PRD) — сейчас всё запускается вручную; для автоматизации можно поставить `collect_report.ps1` в Планировщик заданий Windows.
